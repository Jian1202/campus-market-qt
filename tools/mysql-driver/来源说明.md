# QMYSQL 驱动来源

驱动源码 main.cpp、qsql_mysql.cpp、qsql_mysql_p.h、mysql.json 来自 Qt 官方 qtbase v6.11.1：

https://github.com/qt/qtbase/tree/v6.11.1/src/plugins/sqldrivers/mysql

保留文件头版权及许可证声明。当前 CMakeLists.txt 为独立构建适配，使用本机 Qt 6.11.1 MinGW 的私有头文件和 MySQL 8.4 客户端库。

仅与相同 Qt 版本及编译器环境配套使用；不同版本请重新构建对应版本驱动。MySQL 客户端动态库及许可证来自本机 MySQL Community Server 安装目录。预编译客户端许可证在 Release 运行包的 licenses 目录；Qt 开源许可证文本保留于仓库 third_party/licenses。
