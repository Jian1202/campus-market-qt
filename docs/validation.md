# 验证说明

验证环境：Windows 64 位、Qt 6.11.1 MinGW、MySQL 8.4.9。

- 原项目整理阶段通过71项真实 MySQL 集成检查，覆盖注册、权限、订单、库存联动、取消重购、互评唯一性、信用触发器、举报约束、下架与冻结。
- 从全新交付包解压，在包含中文和空格的路径中创建空构建目录，分别完成 Debug、Release 的 qmake 编译和依赖部署。
- 输出目录没有 exe、没有数据库配置时，仍可先完成链接，再部署依赖与本机配置。
- 将运行时 PATH 限制为 Windows 系统目录，Debug、Release 输出目录中的 QMYSQL 加载和真实数据库连接检查通过。
- 实际检查首页、发布、详情、交易报表、举报处理和管理概览截图。

集成测试需要专用空数据库；不同 Qt 版本、编译器或同学的电脑仍需按开发说明配置。
